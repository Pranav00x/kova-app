# kova-app

React Native (Expo Router) mobile app for Kova — the onchain neobank on Base.

Fresh Phase 1 scaffold per the Kova Master Brief. Not yet wired to any backend or wallet SDK.

## Stack
- Expo + Expo Router
- TypeScript
- Zustand for state
- viem + ZeroDev SDK (to be added) for onchain interactions

## Getting started
```bash
npm install
npm start
```

## Status
Empty scaffold — Phase 1 MVP work (onboarding/KYC, smart account creation, card screen, vault screen) not yet started.
